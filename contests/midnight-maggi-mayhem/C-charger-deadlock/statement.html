Problem C

The Charger Deadlock

Difficulty: medium. Time limit: 1 second.

The hostel has exactly zero spare phone chargers. There are n students, numbered 1 to n, and m notes of the form “student a is waiting for student b”: a can't finish charging until b has finished and handed over the charger.

A student finishes as soon as every student they wait for has finished. Someone who waits for nobody finishes right away. A student can even wait for themselves (don't ask), and the same note can appear more than once.

Some students will be stuck forever. Find them.

Input

The first line contains two integers n and m (1 ≤ n ≤ 2·105, 0 ≤ m ≤ 2·105).

Each of the next m lines contains two integers a and b (1 ≤ a, b ≤ n): student a is waiting for student b.

Output

On the first line, print k, the number of students who never finish.

If k > 0, print on the second line their numbers in increasing order, separated by spaces.

Examples

Sample input 1

6 6
1 2
2 3
3 2
4 5
5 6
4 1

Sample output 1

4
1 2 3 4

Explanation. Students 2 and 3 wait for each other, so neither ever finishes. Student 1 waits for 2, and student 4 waits for 1, so they're stuck too. Student 6 waits for nobody and finishes first, then student 5 can finish.

Sample input 2

3 2
1 2
2 3

Sample output 2

0

Explanation. Student 3 finishes first, then 2, then 1. Nobody is stuck, so only 0 is printed.

Sample input 3

2 1
1 1

Sample output 3

1
1

Explanation. Student 1 is waiting for themselves, which never ends well.
