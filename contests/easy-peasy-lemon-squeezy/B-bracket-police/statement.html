Problem B

Bracket Police

Topic: Stack. Difficulty: easy. Time limit: 1 second.

Your lab partner writes code like they're in a hurry to catch the last bus, and the compiler keeps shouting about brackets. You decide to check their brackets yourself.

A string of brackets ( ) [ ] { } is balanced if every opening bracket is closed by the same kind of bracket, and brackets close in the right order: the one opened last is closed first. So {[()]} and ()[] are balanced, while (], ([)] and )( are not.

Check t strings.

Input

The first line contains an integer t (1 ≤ t ≤ 105).

Each of the next t lines contains a non-empty string of the characters ( ) [ ] { }. The total length of all strings is at most 2·105.

Output

For each string, print YES if it is balanced and NO otherwise, each on its own line.

Examples

Sample input 1

5
()
([]{})
(]
([)]
((

Sample output 1

YES
YES
NO
NO
NO

Explanation. The first two are balanced. In (] the kinds don't match. In ([)] the ( is closed before the [ opened inside it. In (( nothing is ever closed.
