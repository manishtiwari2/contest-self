Problem E

Rotting Oranges (multi-source BFS)

Notes 10.5 · Graphs · LeetCode 994 · Medium. Time limit: 2 seconds.

Every minute, rotten oranges (2) rot fresh neighbours (1). How many minutes until none are fresh? -1 if never.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains rows and cols (1 ≤ rows, cols ≤ 300). Each of the next rows lines has cols numbers, each 0, 1 or 2.

Output

Print the minutes, or -1.

Examples

Sample input 1

3 3
2 1 1
1 1 0
0 1 1

Sample output 1

4

Explanation. The rot spreads from the top-left corner and reaches the bottom-right orange after 4 minutes.

Sample input 2

3 3
2 1 1
0 1 1
1 0 1

Sample output 2

-1

Explanation. The orange in the bottom-left corner can never be reached.

Sample input 3

1 2
0 2

Sample output 3

0

Explanation. Nothing is fresh at the start.

Hint (from the revision notes)
  1. Put all rotten oranges in the queue at the start.
  2. Process the queue one level (one minute) at a time.
  3. At the end, if any fresh orange is left, return -1.
