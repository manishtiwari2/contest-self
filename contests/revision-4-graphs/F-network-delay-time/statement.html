Problem F

Network Delay Time (Dijkstra)

Notes 11.1 · Advanced Graphs · LeetCode 743 · Medium. Time limit: 2 seconds.

A signal starts at node k. times[i] = {u, v, w}. How long until every node gets it? -1 if some never do.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n, m and k (1 ≤ n ≤ 105, 0 ≤ m ≤ 2·105, 1 ≤ k ≤ n). Each of the next m lines contains u, v and w (1 ≤ u, v ≤ n, 0 ≤ w ≤ 104): a one-way edge. Nodes stay numbered 1 to n, as in the PDF code.

Output

Print the time, or -1.

Examples

Sample input 1

4 3 2
2 1 1
2 3 1
3 4 1

Sample output 1

2

Explanation. From node 2, nodes 1 and 3 get it at time 1, and node 4 at time 2.

Sample input 2

2 1 2
1 2 1

Sample output 2

-1

Explanation. The signal starts at node 2 and the only edge goes from 1 to 2.

Hint (from the revision notes)
  1. dist[k] = 0, everything else infinity.
  2. Take the node with the smallest distance from the priority queue.
  3. If its entry is old (bigger than dist), skip it. Otherwise relax its edges.
  4. The answer is the biggest distance.
