Problem H

Edit Distance

Notes 13.4 · 2-D Dynamic Programming · LeetCode 72 · Medium. Time limit: 2 seconds.

Fewest insert / delete / replace steps to turn word a into word b.

Write only the function: the starter code already reads the input and prints your answer.

Input

Two lines: the words a and b, each with 0 to 500 lowercase letters (an empty word is an empty line).

Output

Print the number of steps.

Examples

Sample input 1

horse
ros

Sample output 1

3

Explanation. horse → rorse (replace) → rose (delete) → ros (delete).

Sample input 2

intention
execution

Sample output 2

5

Explanation. Five steps.

Hint (from the revision notes)
  1. dp[i][j] = steps for the first i letters of a and the first j of b.
  2. Empty strings: dp[i][0] = i, dp[0][j] = j.
  3. Same letter: dp[i-1][j-1]. Otherwise 1 + the smallest of replace, delete, insert.
