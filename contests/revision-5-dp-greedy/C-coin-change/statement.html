Problem C

Coin Change

Notes 12.3 · 1-D Dynamic Programming · LeetCode 322 · Medium. Time limit: 2 seconds.

Fewest coins that make the amount. -1 if impossible. Coins can be used many times.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n and amount (1 ≤ n ≤ 12, 0 ≤ amount ≤ 104). The second line contains n different coin values (1 ≤ coins[i] ≤ 104).

Output

Print the fewest coins, or -1.

Examples

Sample input 1

3 11
1 2 5

Sample output 1

3

Explanation. 5 + 5 + 1.

Sample input 2

1 3
2

Sample output 2

-1

Explanation. 2s can't make 3.

Sample input 3

1 0
1

Sample output 3

0

Explanation. Making 0 needs no coins.

Hint (from the revision notes)
  1. dp[x] = fewest coins to make x. dp[0] = 0.
  2. For each coin c <= x: dp[x] = min(dp[x], dp[x - c] + 1).
  3. Greedy (always the biggest coin) fails: coins [1, 3, 4], amount 6 gives 4+1+1, but 3+3 is better.
