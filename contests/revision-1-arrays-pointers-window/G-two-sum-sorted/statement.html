Problem G

Two Sum II (sorted input)

Notes 2.2 · Two Pointers · LeetCode 167 · Medium. Time limit: 2 seconds.

The array is sorted. Find two numbers with sum = target. Return 1-based positions.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n and target (2 ≤ n ≤ 105, −109 ≤ target ≤ 109). The second line contains n integers in increasing order (repeats allowed, −109 ≤ nums[i] ≤ 109). Exactly one pair adds up to target.

Output

Print the two positions a and b (1-based, a < b).

Examples

Sample input 1

4 9
2 7 11 15

Sample output 1

1 2

Explanation. 2 + 7 = 9, at positions 1 and 2.

Sample input 2

2 -1
-1 0

Sample output 2

1 2

Explanation. -1 + 0 = -1.

Hint (from the revision notes)
  1. Sum too small? Move left to the right (bigger number).
  2. Sum too big? Move right to the left (smaller number).
  3. Sorting is what makes each move safe.
