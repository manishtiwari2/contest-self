Problem A

Valid Parentheses

Notes 4.1 · Stack · LeetCode 20 · Easy. Time limit: 2 seconds.

Check if the brackets ( ) [ ] { } are closed in the right order by the right type.

Write only the function: the starter code already reads the input and prints your answer.

Input

One line: the string s, with 1 to 105 characters, each one of ( ) [ ] { }.

Output

Print true or false.

Examples

Sample input 1

()[]{}

Sample output 1

true

Explanation. Each pair closes right after it opens.

Sample input 2

([)]

Sample output 2

false

Explanation. The ( is closed before the [ inside it.

Hint (from the revision notes)
  1. Opening bracket: push it.
  2. Closing bracket: the top of the stack must be its partner. Pop it.
  3. At the end the stack must be empty.
