Problem J

Merge Two Sorted Lists

Notes 6.2 · Linked List · LeetCode 21 · Easy. Time limit: 2 seconds.

Merge two sorted lists into one sorted list.

Write only the function: the starter code already reads the input and prints your answer.

Input

Line 1: n. Line 2: the n values of list a. Line 3: m. Line 4: the m values of list b. Both lists are sorted (0 ≤ n, m ≤ 105, n + m ≥ 1, −109 ≤ value ≤ 109). An empty list has an empty line.

Output

The starter code prints the merged list.

Examples

Sample input 1

3
1 2 4
3
1 3 4

Sample output 1

1 1 2 3 4 4

Explanation. Take the smaller front value each time.

Hint (from the revision notes)
  1. A dummy node gives us a place to attach to, so there is no special case for the first node.
  2. Attach the smaller front node each time.
  3. When one list ends, attach the rest of the other one.
