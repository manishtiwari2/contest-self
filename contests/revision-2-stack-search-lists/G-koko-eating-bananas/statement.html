Problem G

Koko Eating Bananas

Notes 5.3 · Binary Search · LeetCode 875 · Medium. Time limit: 2 seconds.

Koko eats k bananas per hour from one pile. Find the smallest k so she finishes all piles in h hours.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n and h (1 ≤ n ≤ 104, n ≤ h ≤ 109). The second line contains n piles (1 ≤ piles[i] ≤ 109).

Output

Print the smallest speed k.

Examples

Sample input 1

4 8
3 6 7 11

Sample output 1

4

Explanation. At speed 4 the piles take 1 + 2 + 2 + 3 = 8 hours. Speed 3 needs 10.

Sample input 2

5 5
30 11 23 4 20

Sample output 2

30

Explanation. With 5 hours for 5 piles she must finish the biggest pile (30) in one hour.

Hint (from the revision notes)
  1. If speed k works, every bigger speed works too. So binary search on k.
  2. For one speed, the hours are the sum of pile / k, rounded up.
  3. Search between 1 and the biggest pile.
