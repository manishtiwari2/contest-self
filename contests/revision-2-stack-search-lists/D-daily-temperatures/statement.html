Problem D

Daily Temperatures

Notes 4.4 · Stack · LeetCode 739 · Medium. Time limit: 2 seconds.

For each day, how many days until a warmer day? 0 if never.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n (1 ≤ n ≤ 105). The second line contains n temperatures (30 ≤ temps[i] ≤ 100).

Output

Print n numbers.

Examples

Sample input 1

8
73 74 75 71 69 72 76 73

Sample output 1

1 1 4 2 1 1 0 0

Explanation. Day 3 (75) waits until day 7 (76): 4 days. The last two days never see a warmer day.

Hint (from the revision notes)
  1. The stack holds days that are still waiting for a warmer day.
  2. When today is warmer than the day on top, that day got its answer: pop it.
  3. Then push today.
