Problem M

Remove Nth Node From End of List

Notes 6.5 · Linked List · LeetCode 19 · Medium. Time limit: 2 seconds.

Remove the n-th node from the end, in one pass.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains size and n (1 ≤ n ≤ size ≤ 105). The second line contains the size values of the list.

Output

The starter code prints the list after the removal (an empty line if nothing is left).

Examples

Sample input 1

5 2
1 2 3 4 5

Sample output 1

1 2 3 5

Explanation. The 2nd node from the end is 4.

Sample input 2

1 1
1

Sample output 2

Explanation. Removing the only node leaves an empty list.


Hint (from the revision notes)
  1. Move fast n + 1 steps ahead of slow (both start at a dummy).
  2. Move both until fast is null. Now slow is just before the node to remove.
  3. The dummy handles removing the head itself.
