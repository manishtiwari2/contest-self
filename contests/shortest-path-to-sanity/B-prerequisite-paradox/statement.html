Problem B

The Prerequisite Paradox

Difficulty: medium. Time limit: 2 seconds.

The college ERP lets professors add course prerequisites. There are n courses, numbered 1 to n. Rule “a b” means: to take course a, you must first pass course b.

The rules are added one by one. The ERP is fine as long as no course ends up needing itself, directly or through a chain of other courses (“DSA needs Maths, Maths needs Physics, Physics needs DSA”). The moment that happens, nobody can graduate and the ERP crashes. Classic.

After which rule does it crash?

Input

The first line contains two integers n and m (1 ≤ n ≤ 105, 1 ≤ m ≤ 105).

The next m lines contain the rules in the order they are added, rule i on line i. Each has two integers a and b (1 ≤ a, b ≤ n). A course can need itself (a = b), and the same rule can appear more than once.

Output

Print the smallest k such that rules 1 to k make some course need itself, or -1 if the ERP survives all m rules.

Examples

Sample input 1

4 5
1 2
2 3
3 4
4 2
1 3

Sample output 1

4

Explanation. After rule 4, course 2 needs 3, course 3 needs 4, and course 4 needs 2 again: a loop. Nothing before rule 4 made one.

Sample input 2

3 3
1 2
1 3
2 3

Sample output 2

-1

Explanation. Course 3 is needed by both 1 and 2, but there is no loop: pass 3, then 2, then 1.

Sample input 3

3 3
1 2
3 3
2 1

Sample output 3

2

Explanation. Rule 2 says course 3 needs course 3 itself.
