Problem O

Power of Two

Notes 17.5 · Bit Manipulation · LeetCode 231 · Easy. Time limit: 2 seconds.

Is n a power of two?

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains q (1 ≤ q ≤ 105). Each of the next q lines contains n (−231 ≤ n ≤ 231 − 1).

Output

For each n, print true or false.

Examples

Sample input 1

5
1
16
6
0
-8

Sample output 1

true
true
false
false
false

Explanation. 1 = 2<sup>0</sup> and 16 = 2<sup>4</sup>. 6 has two 1-bits. 0 and negative numbers are never powers of two.

Hint (from the revision notes)
  1. A power of two has exactly one 1-bit, so removing it gives 0.
  2. n must be > 0.
