Problem D

Meeting Rooms II

Notes 15.4 · Intervals · LeetCode 253 · Medium. Time limit: 2 seconds.

How many rooms are needed for all meetings?

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n (1 ≤ n ≤ 105). Each of the next n lines contains start and end (0 ≤ start < end ≤ 106). A room is free again exactly at a meeting's end time.

Output

Print the number of rooms.

Examples

Sample input 1

3
0 30
5 10
15 20

Sample output 1

2

Explanation. [0, 30] needs its own room. [5, 10] and [15, 20] can share one.

Sample input 2

2
7 10
2 4

Sample output 2

1

Explanation. No overlap: one room.

Hint (from the revision notes)
  1. Sort by start. A min-heap holds the end times of rooms in use.
  2. If the room that frees first is free by now, reuse it (poll).
  3. Push this meeting's end. The heap size is the number of rooms.
