Problem B

Invert Binary Tree

Notes 7.2 · Trees · LeetCode 226 · Easy. Time limit: 2 seconds.

Mirror the tree: swap left and right everywhere.

Write only the function: the starter code already reads the input and prints your answer.

Input

The first line contains n, the number of tokens. The second line describes the tree level by level, like on LeetCode: node values, with null for a missing child (for example 3 9 20 null null 15 7). The tree has up to 40,000 nodes. The tree is not empty.

Output

The starter code prints the mirrored tree in the same level-order format.

Examples

Sample input 1

7
4 2 7 1 3 6 9

Sample output 1

4 7 2 9 6 3 1

Explanation. Every node's children are swapped.

Sample input 2

2
2 1

Sample output 2

2 null 1

Explanation. The left child becomes the right child.

Hint (from the revision notes)
  1. Swap the two children of this node.
  2. Do the same for both children (recursion).
